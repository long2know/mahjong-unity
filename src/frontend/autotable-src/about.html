Mahjong Unity

The browser retains the established lobby, chat, multiplayer client, Changsha server rules and four collaborative tabletop variants. Unity renders the table and handles picking.

Choose perspective or flat view, a classic or rectangular board, and an in-table or separate local hand in Display settings. Automatic layout fits narrow screens.

A missing Unity build is reported explicitly. The browser never substitutes the retired JavaScript renderer.

Source and notices

Browser/model source is derived from long2know/mahjong-autotable, based on pwmarcz/autotable. The pinned baseline is recorded in UPSTREAM_SHA.

The retained upstream license notice is in COPYING. Repository third-party notices and licensing decisions govern redistribution of fork additions. Original label cards and the app icon replace the excluded noncommercial tile/art/font/media assets.
